# 五段式空白模板

占位符只用于填报与待补证草稿，不可带入投递终稿。没有做过的机制删除或按当前阶段注明，不靠填空制造经历。

```text
{{项目名称}}｜{{实际起止时间}}｜{{实际角色}}
技术栈：{{实际使用的语言/运行基础、存储、框架、模型、算法组件}}

项目介绍：面向{{具体场景}}，针对{{已观察的问题}}，构建/扩展{{系统或训练流程}}，支持{{已经实现的目标}}。

- 底盘层：针对{{运行/数据/实验风险}}，在{{具体模块}}实现/扩展{{真实机制}}，支持{{已确认能力}}。
- 架构层：设计{{主要数据流或训练流}}；实现{{本人负责的关键模块}}，并明确{{复用与新增边界}}。
- 治理层：记录{{实际观测字段}}，通过{{实际诊断/异常处理}}处理{{已发生的问题}}；以{{已经执行的回归}}检查修复。
- 评测层：基于{{来源、版本、分割，N 与统计单位，有效评分分母}}，在{{相同条件与预算}}下比较{{基线/当前策略}}；{{核心指标}}由{{基线值}}变为{{当前值}}（{{差值与正确单位}}）。

项目成果：在{{数据范围与协议}}上，{{量化效果摘要}}；端到端{{P50/P95 等实测统计量}}由{{基线值与单位}}变为{{当前值与单位}}（{{变化}}），单{{题/任务}}成本由{{基线金额}}变为{{当前金额}}（{{变化比例}}）；选择{{方案}}以{{实测代价}}换取{{已验证效果}}。
边界说明：{{开发回归/单次观测/非等算力/部署范围等关键边界}}；{{不能由现有证据推出的结论}}。
```
<!-- TEMPLATE_END -->

延迟或成本未测时，删除对应占位句，在内部核对中注明未测；不得填零或“无额外开销”。没有效果基线但有单组实测结果时，报告指标值与分母，不写提升。完全没有效果实验但确有交付时，将成果段替换为：

```text
项目成果：完成{{真实模块/工具/测试/评测产物}}，覆盖{{已经验证的具体范围}}。
边界说明：当前完成{{真实阶段}}，尚未开展{{未做事项}}，不报告未经验证的效果提升。
```

后训练中的“底盘”可对应训练循环、配置冻结、数据隔离或奖励契约；不要强套租约、SSE 和 Web Runtime。
